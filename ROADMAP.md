# Blitz Panel Roadmap

Цель проекта: чтобы человек мог поставить панель одной командой с GitHub и сразу получить рабочий AmneziaWG VPN без ручной подготовки сервера.

## Уже в панели

- установка одной командой;
- серверное меню `blits`;
- Amnezia 2.0 / 3.1 и Amnezia 1 / Legacy;
- отдельные конфиги и QR-коды для разных версий AmneziaVPN;
- полный и раздельный туннель;
- маршруты Google/YouTube для split tunnel;
- настройки порта, домена, языка, темы, web path и API token;
- бэкапы;
- self-check после установки.

## Что добавляем дальше

1. Мастер первого запуска: пароль, домен/IP, HTTPS, DNS, split tunnel и проверка подключения.
2. Кнопка "Проверить все" в панели с понятными статусами и быстрыми действиями.
3. Полное редактирование клиента без смены ключей и IP.
4. Автоматическое обновление online/offline статусов клиентов.
5. Проверка QR-кодов и автоматическое разбиение на части для AmneziaVPN.
6. Бэкап перед каждым опасным действием.
7. Обновление панели из веб-интерфейса с логом и безопасным fallback в терминал.
8. Xray как отдельный модуль: VLESS/Reality, UUID, порт, домен, ссылки и QR.
9. Полная мобильная версия без горизонтального скролла.
10. Журнал действий администратора.
11. Проверка домена, DNS A-записи, HTTPS и срока сертификата.
12. Импорт и экспорт клиентов.
13. Режим миграции на новый сервер без перевыпуска клиентских ключей при доменном endpoint.
14. Автоматическая проверка открытых UDP/TCP портов с подсказкой, что исправить.
15. Уведомления в Telegram о падении VPN, истечении сертификата и окончании подписок.
16. Лимиты скорости и трафика на клиента с понятной индикацией.
17. Группы клиентов: семья, друзья, тест, бизнес.
18. Роли панели: владелец, администратор, только просмотр.
19. Страница "Здоровье сервера": CPU, RAM, диск, нагрузка, Docker, awg, последние ошибки.
20. Автоматический restore-тест бэкапа в отдельной временной проверке.

## Ближайший порядок

Сначала укрепляем AmneziaWG-часть: редактирование клиентов, статусы, диагностика, QR и бэкапы. После этого добавляем Xray отдельным разделом, чтобы не смешивать разные протоколы и не ломать текущие ключи AmneziaWG.
