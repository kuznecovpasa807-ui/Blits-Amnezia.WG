# Blitz AmneziaWG Panel

Простая веб-панель для управления AmneziaWG VPN.

Панель умеет создавать клиентов, показывать QR-коды для AmneziaVPN, работать с Amnezia 2.0 и Amnezia 1 / Legacy, настраивать раздельное туннелирование, делать бэкапы и управляться через серверное меню `blits`.

## Установка

Запустите команду на сервере от root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Blits-dev-vibe/Blits-Amnezia.WG/main/install.sh)
```

Установщик сам поставит нужные пакеты, настроит AmneziaWG и запустит панель.

## После установки

Откройте серверное меню:

```bash
blits
```

В меню можно:

- посмотреть адрес панели;
- сменить порт панели;
- сменить домен;
- изменить секретный web-путь;
- перегенерировать API token;
- сменить пароль администратора;
- посмотреть логи;
- создать или восстановить бэкап;
- перезапустить панель.

## Обновление

```bash
cd /root/Blits-Amnezia.WG
git pull origin main
docker compose up -d --build
```

Если панель работает через SSL:

```bash
docker compose --profile ssl up -d --build
```

## VPN-профили

Панель создает два варианта подключения:

- `Amnezia 2.0` - основной профиль;
- `Amnezia 1 / Legacy` - профиль для старой версии приложения AmneziaVPN.

Для приложения AmneziaVPN QR-код может состоять из нескольких частей. В панели они показываются по очереди, чтобы их было удобно сканировать с телефона.

## Бэкапы

Бэкап можно скачать из веб-панели или создать через меню:

```bash
blits
```

В бэкап входят база клиентов, настройки панели и VPN-конфиги.

## Важно

Не публикуйте в открытом доступе:

- `.env`;
- `data/panel.db`;
- приватные ключи;
- токены;
- резервные копии.

Эти файлы содержат доступы и VPN-ключи.
